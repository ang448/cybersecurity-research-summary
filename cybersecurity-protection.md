# Cyber Security Protection
There are many ways to protect your organisation against cyber threats. This is done using technology, policies and human behavior. There are multiple ways to protect your organisation.
## Using strong unique passwords

Use a unique password for each important account. You could use a reliable password manager to help generate unique passwords. Never share your passwords.
## Multi-Factor Authentication

Use Multi-Factor Authentication. This means that you will have to have an extra method to log into your account such as an Authenticator app or security key. This will help reduce risks of someone stealing your password to log into your account.
## Keeping software updated
Have any updates installed for the Operating System, apps and devices. This usually includes security changes to help prevent any issues. If possible have the software update automatically.

## Firewalls and Virus Protection

A firewall can help secure your network by controlling your network traffic. Antivirus/endpoint protection can help identify and deal with malicious files. Make sure your software is up to date and set up properly.
## Backups

Regularly back up important information. Keep your backups secure and if possible have them in a separate or off-line location. Check that files can be retrieved.
## Be aware of suspicious content

Know what to look out for when receiving suspicious messages, links and attachments. Check any odd requests using a trusted source and quickly report any suspected incidents to the relevant IT/security team.
## Limit access

Only give users the access they need to do their job. Regularly check that users are only given appropriate access and remove any unnecessary access.
## Summary

A good Cyber Security strategy includes multiple ways to protect the organisation. This includes having secure accounts, updated systems, secure backups, sensible access and aware users.
